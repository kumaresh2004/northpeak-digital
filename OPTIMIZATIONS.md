# Optimisations Made

## 1. Modern Responsive Design
Built a fully responsive landing page that works across desktop, tablet, and mobile devices using flexible layouts and media queries.

## 2. Component-Based Architecture
Structured the project using reusable React components such as Navbar, Hero, Services, Testimonials, Pricing, Contact, CTA, and Footer for better maintainability.

## 3. Performance
Optimized layout with lightweight React components, efficient CSS, and minimized unnecessary re-renders.

## 4. User Experience
Added smooth scrolling, clean navigation, clear call-to-action buttons, and a simple layout to improve usability.

## 5. Visual Improvements
Used gradients, consistent spacing, modern typography, hover effects, and card-based layouts to create a professional appearance.

## 6. Mobile Optimization
Implemented responsive navigation and ensured all sections adapt properly to different screen sizes.

## 7. Code Organization
Separated components and styles into dedicated folders, making the project easier to read, maintain, and scale.

## AI Usage
AI tools were used to brainstorm UI ideas, improve content wording, and assist with debugging. Final implementation, customization, testing, and design decisions were completed manually.
